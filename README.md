# كيمياء السادس | افهمها قبل لا تحفظها

منصة عربية RTL مبنية بـ React وTypeScript وVite وTailwind CSS وFramer Motion وKaTeX. تبقى الصفحة القديمة `chemistry-chapter-1.html` محفوظة كما هي.

## التشغيل

المتطلبات: Node.js 22 أو أحدث وnpm.

```sh
npm ci
npm run dev -- --port 5173
```

```sh
npm run build
npm test
```

`dist/` ناتج ثابت قابل للنشر. لا يحتاج التطبيق إلى قاعدة بيانات أو أسرار أو خدمات خارجية. الخطوط والمصدر وPDF worker محفوظة محلياً. PDF الأصلي كبير (نحو 30 MB) ويُحمّل عند فتحه فقط. نص المصدر وPDF.js يُحمّلان عند الحاجة.

## التحقق

- `npm test`: ثلاثة اختبارات لمعادلة اتزان N₂O₄، واتزان الحامض الضعيف، وطاقة گبس وجدولة المراجعة.
- شغّل خادم التطوير، ثم `python3 tests/browser_smoke.py` في بيئة يتوفر فيها Python Playwright وChromium في `/usr/bin/chromium`. يمكن تغيير وجهة الاختبار بمتغير `APP_URL`.
- `python3 tests/source_upload_smoke.py`: يرفع الملزمة الأصلية ويستخرج صفحاتها الـ119 ويتنقل في أوضاع الدروس للفصول السبعة على شاشة هاتف.
- اختبار المتصفح يتحقق من المحاكاة، الإجابة الخاطئة والصحيحة، استعادة التقدم، الوضع الليلي، البحث في المصدر، عارض PDF والتنقل على الهاتف. صور التحقق تُحفظ في `/tmp/`.

## نطاق المحتوى ومصدره

- سبعة فصول بترتيب الملزمة المرفقة و22 درساً تأسيسياً مع شرح وتعليل ومقارنة وبطاقة واختبار تدريبي لكل درس.
- المصدر: **كلاميات الكيمياء السادس العلمي، الأستاذ نور الدين الدليمي، 2026**، المرفق من المستخدم؛ محفوظ في `public/chemistry-source.pdf` (119 صفحة). يضم `src/source.json` النص القابل للاستخراج من الصفحات غير الفارغة، مع أرقام صفحات PDF الأصلية.
- المصدر ملزمة، وليس الكتاب المدرسي الرسمي. الصياغات في `src/data.ts` تعليمية وليست نقلاً حرفياً معتمداً للتعاريف الوزارية. الإحالات تشير إلى صفحات موضوعية للمراجعة.
- جميع صفحات المصدر متاحة، لكن تحويل **كل** تعاريفه وتعاليله ومقارناته إلى دروس مراجعة علمياً غير مكتمل؛ الدروس الـ22 لا تمثّل جميع كلاميات المنهج. يلزم الكتاب الرسمي والتحقق العلمي لاستكمال المطابقة قبل وصف المنصة بأنها تغطي المنهج كاملاً.
- بعض النصوص والجداول والمعادلات في PDF تحتوي ترميزاً غير سليم عند الاستخراج؛ اعتمد صورة الصفحة الأصلية، ولا تعتمد النص المستخرج وحده للحفظ.
- الأسئلة الـ22 تدريبية من إعداد المنصة؛ لا توجد أسئلة مصنفة كوزارية موثّقة. ظهور سنة وزارية في الملزمة وحده لا يثبت نسبتها دون ورقة الامتحان.
- رفع PDF واستخراجه يتم محلياً في المتصفح. الملف المرفوع يبقى في الجلسة ولا يستبدل الدروس تلقائياً. إعادة التحميل تعيد المصدر المرفق.

## النماذج العلمية

`src/science.js` يحوي النماذج القابلة للاختبار. نموذج الاتزان غاز مثالي لـ N₂O₄ ⇌ 2NO₂ مع Kp(298 K)=1 للتعليم، وإنثالبية تفكك ثابتة تقريبياً 57 kJ/mol. نموذج الحامض الضعيف يحل اتزان حامض أحادي البروتون عند Ka=1.8×10⁻⁵ مع إهمال تأين الماء ومعاملات الفعالية. نموذج گبس يستخدم قيماً تعليمية معلنة. بقية الرسوم مفاهيمية وتوضح حدودها داخل الواجهة؛ ليست نماذج جزيئية ثلاثية الأبعاد أو تجارب كمية.

التقدم وحالة المظهر وآخر درس محفوظة محلياً في LocalStorage. المراجعة الصحيحة تجدول البطاقة بعد 1، 3، 7، 14 ثم 30 يوماً، والخطأ يبقى مستحقاً للمراجعة.
